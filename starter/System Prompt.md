# System Prompt · Instrucción de sistema

**En simple.** Son las instrucciones de fondo que definen el rol, el tono y los límites de una IA antes de que la persona escriba nada. Orientan todas sus respuestas.

**Técnica.** Instrucción de alto nivel que define comportamiento, rol y restricciones de un modelo.

**Ejemplo de uso.** _La instrucción de sistema le prohíbe inventar precios._

---

**In simple.** The background instructions that define an AI's role, tone and limits before the person types anything. They guide all of its answers.

**Technical.** A high-level instruction that defines a model's behavior, role and constraints.

**Example.** _The system prompt forbids it from making up prices._
