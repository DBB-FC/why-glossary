# REST API · API REST

**En simple.** Es un estilo muy usado de API web, basado en HTTP, donde cada recurso tiene una dirección y se opera con acciones estándar como leer, crear o borrar.

**Técnica.** Estilo de API basado habitualmente en HTTP, recursos y métodos estandarizados.

**Ejemplo de uso.** _La API REST expone clientes y pedidos._

---

**In simple.** A widely used style of web API, based on HTTP, where each resource has an address and is operated with standard actions such as reading, creating or deleting.

**Technical.** An API style usually built on HTTP, resources and standard methods.

**Example.** _The REST API exposes customers and orders._
