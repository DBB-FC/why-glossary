# SDK · Kit de desarrollo de software

**En simple.** Es un paquete de herramientas y librerías que facilita usar un servicio o plataforma desde tu propio código.

**Técnica.** Software Development Kit: herramientas y librerías para integrar/desarrollar sobre una plataforma.

**Ejemplo de uso.** _Usamos el SDK del proveedor de pagos._

---

**In simple.** A package of tools and libraries that makes it easier to use a service or platform from your own code.

**Technical.** Software Development Kit: tools and libraries to integrate with or build on a platform.

**Example.** _We use the payment provider's SDK._
