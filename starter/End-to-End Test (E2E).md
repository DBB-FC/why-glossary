# End-to-End Test (E2E) · Prueba de extremo a extremo

**En simple.** Es una prueba que recorre un flujo completo como lo haría una persona usuaria, de principio a fin, por ejemplo desde entrar al sitio hasta pagar.

**Técnica.** Prueba de un flujo completo desde la perspectiva del usuario.

**Ejemplo de uso.** _La prueba E2E recorre el flujo de cotización completo._

---

**In simple.** A test that walks through a whole flow the way a user would, from start to finish, for example from landing on the site to paying.

**Technical.** A test of a complete flow from the user's perspective.

**Example.** _The E2E test walks the whole quote flow._
