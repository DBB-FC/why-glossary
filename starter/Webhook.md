# Webhook · Webhook (aviso automático entre sistemas)

**En simple.** Es un aviso automático que un sistema le envía a otro cuando ocurre algo, por ejemplo cuando se confirma un pago, sin que el segundo tenga que preguntar.

**Técnica.** Notificación HTTP automática disparada por un evento.

**Ejemplo de uso.** _El banco nos avisa por webhook cuando llega el pago._

---

**In simple.** An automatic notice one system sends another when something happens, for example when a payment is confirmed, without the second having to ask.

**Technical.** An automatic HTTP notification triggered by an event.

**Example.** _The bank notifies us by webhook when the payment arrives._
