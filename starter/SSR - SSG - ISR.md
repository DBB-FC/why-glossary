# SSR / SSG / ISR · Renderizado en servidor / generación estática / regeneración incremental

**En simple.** Son tres formas de armar una página web: en el servidor al pedirla (SSR), por adelantado al publicar (SSG), o rearmada cada cierto tiempo (ISR).

**Técnica.** Renderizado en el servidor, generación estática en compilación, o regeneración incremental.

**Ejemplo de uso.** _El blog usa SSG y la tienda usa SSR._

---

**In simple.** Three ways of building a web page: on the server when it is requested (SSR), ahead of time when published (SSG), or rebuilt every so often (ISR).

**Technical.** Server-side rendering, static generation at build time, or incremental regeneration.

**Example.** _The blog uses SSG and the shop uses SSR._
