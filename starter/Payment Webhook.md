# Payment Webhook · Webhook de pago

**En simple.** «Este pago quedó aprobado.»

**Técnica.** Notificación que el proveedor envía al comercio cuando cambia el estado de una transacción.

**Ejemplo de uso.** _El webhook de pago confirmó la aprobación._
