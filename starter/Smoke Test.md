# Smoke Test · Prueba de humo

**En simple.** Es una verificación rápida de lo esencial, hecha después de publicar una versión, para saber si vale la pena seguir probando o si algo básico está roto.

**Técnica.** Conjunto breve de pruebas críticas para comprobar que una versión es utilizable.

**Ejemplo de uso.** _Tras el despliegue hicimos una prueba de humo._

---

**In simple.** A quick check of the essentials, done after releasing a version, to know whether it is worth testing further or whether something basic is broken.

**Technical.** A short set of critical tests to check a build is usable.

**Example.** _After the deployment we ran a smoke test._
