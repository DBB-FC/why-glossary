# Data Lake · Lago de datos

**En simple.** Es un repositorio donde se guardan grandes volúmenes de datos tal como llegan, en formatos variados y sin estructura fija. Es más flexible que un almacén de datos, pero más desordenado.

**Técnica.** Repositorio que almacena grandes volúmenes de datos en formatos diversos.

**Ejemplo de uso.** _Guardamos los archivos crudos en el lago de datos._

---

**In simple.** A repository where large volumes of data are kept as they arrive, in varied formats and with no fixed structure. It is more flexible than a data warehouse, but messier.

**Technical.** A repository that stores large volumes of data in varied formats.

**Example.** _We keep the raw files in the data lake._
