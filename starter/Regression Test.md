# Regression Test · Prueba de regresión

**En simple.** Es una prueba que se repite después de cada cambio para comprobar que lo nuevo no rompió algo que ya funcionaba.

**Técnica.** Prueba destinada a comprobar que cambios nuevos no rompieron funciones existentes.

**Ejemplo de uso.** _Corrimos regresión antes de liberar el arreglo._

---

**In simple.** A test repeated after every change to check that the new work did not break something that already worked.

**Technical.** A test meant to verify that new changes didn't break existing features.

**Example.** _We ran regression before releasing the fix._
