# Design System · Sistema de diseño

**En simple.** Es un conjunto documentado de componentes, colores, tipografías y reglas de diseño que se reutilizan en todo el producto para que se vea y funcione de forma coherente.

**Técnica.** Sistema documentado de componentes, reglas, tokens y patrones reutilizables.

**Ejemplo de uso.** _El sistema de diseño unifica las tres apps._

---

**In simple.** A documented set of components, colors, typefaces and design rules reused across a whole product so that it looks and works consistently.

**Technical.** A documented set of reusable components, rules, tokens and patterns.

**Example.** _The design system unifies the three apps._
