# Constraint · Restricción

**En simple.** Es una regla que la base de datos impone sobre los datos y que no se puede saltar, como que un precio no sea negativo. No depende de que el código se acuerde de revisarlo.

**Técnica.** Regla que la base impone sobre los datos y no se puede saltar.

**Ejemplo de uso.** _Una restricción impide precios negativos._

---

**In simple.** A rule the database enforces on data and that cannot be bypassed, such as a price not being negative. It does not depend on the code remembering to check.

**Technical.** A rule the database enforces on data and that can't be bypassed.

**Example.** _A constraint prevents negative prices._
