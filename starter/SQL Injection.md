# SQL Injection · Inyección SQL

**En simple.** Es un ataque en que alguien escribe código SQL en un campo de entrada, como un formulario, para engañar a la base de datos y leer o modificar datos que no debería.

**Técnica.** Ataque que manipula consultas SQL mediante entradas no controladas.

**Ejemplo de uso.** _Parametrizamos las consultas para evitar inyección SQL._

---

**In simple.** An attack where someone types SQL code into an input field, such as a form, to trick the database into reading or changing data it should not.

**Technical.** An attack that manipulates SQL queries through uncontrolled input.

**Example.** _We parameterized queries to prevent SQL injection._
