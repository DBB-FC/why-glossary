# Trigger (DB) · Disparador (base de datos)

**En simple.** Es un código guardado en la base de datos que se ejecuta solo cuando alguien inserta, cambia o borra un dato. Es útil, pero cuesta ver cuándo falla.

**Técnica.** Función que la base ejecuta automáticamente ante un cambio.

**Ejemplo de uso.** _Un trigger actualiza la fecha de modificación._

---

**In simple.** Code stored in the database that runs by itself when someone inserts, changes or deletes data. It is useful, but it is hard to see when it fails.

**Technical.** A function the database runs automatically on a change.

**Example.** _A trigger updates the modification date._
