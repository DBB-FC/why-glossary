# Legacy System · Sistema heredado

**En simple.** Es un software antiguo que todavía sostiene una parte importante del negocio, pero cuya tecnología es difícil de mantener o de cambiar.

**Técnica.** Sistema antiguo que continúa siendo crítico pero puede presentar limitaciones tecnológicas.

**Ejemplo de uso.** _El sistema heredado sigue emitiendo las facturas._

---

**In simple.** Old software that still holds up an important part of the business, but whose technology is hard to maintain or change.

**Technical.** An old system that remains critical but may have technological limitations.

**Example.** _The legacy system still issues the invoices._
