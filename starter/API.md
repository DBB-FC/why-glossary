# API · Interfaz de programación de aplicaciones

**En simple.** Es un conjunto de reglas que permite que un programa le pida datos o acciones a otro, sin conocer cómo funciona por dentro. Es la «ventanilla» de un sistema.

**Técnica.** Application Programming Interface: contrato que permite interacción programática entre sistemas.

**Ejemplo de uso.** _Conectamos el CRM por API._

---

**In simple.** A set of rules that lets one program ask another for data or actions without knowing how it works inside. It is a system's «service window».

**Technical.** Application Programming Interface: a contract enabling programmatic interaction between systems.

**Example.** _We connected the CRM through its API._
