# Repository · Repositorio

**En simple.** Es el lugar donde se guarda el código de un proyecto junto con todo su historial de cambios.

**Técnica.** Almacén versionado que contiene código y archivos asociados al proyecto.

**Ejemplo de uso.** _El repositorio tiene tres ramas activas._

---

**In simple.** The place where a project's code is stored together with its full history of changes.

**Technical.** A versioned store holding the code and files of a project.

**Example.** _The repository has three active branches._
