# Backup · Respaldo

**En simple.** Es una copia de tus datos guardada aparte, para poder recuperarlos si se pierden, se dañan o se borran por error.

**Técnica.** Copia recuperable de datos o sistemas.

**Ejemplo de uso.** _Hacemos un respaldo cada noche._
