# SSE (Server-Sent Events) · Eventos enviados por el servidor

**En simple.** Es una conexión en que el servidor envía datos al navegador de forma continua, sobre HTTP, sin que este tenga que pedirlos. Es más simple que WebSocket cuando solo habla el servidor.

**Técnica.** Server-Sent Events: flujo unidireccional del servidor al cliente sobre HTTP.

**Ejemplo de uso.** _Mostramos el progreso con SSE._

---

**In simple.** A connection where the server sends data to the browser continuously, over HTTP, without it having to ask. It is simpler than WebSocket when only the server talks.

**Technical.** Server-Sent Events: a one-way stream from server to client over HTTP.
