# N+1 · Problema de consultas N+1

**En simple.** Es un error de rendimiento en que se hace una consulta por cada fila de un resultado en vez de una sola para todas. Con 40 filas, son 41 consultas.

**Técnica.** Patrón donde se hace una consulta por cada fila de un resultado.

**Ejemplo de uso.** _El N+1 hacía lenta la lista de pedidos._

---

**In simple.** A performance mistake where one query is made for each row of a result instead of one for all of them. With 40 rows, that is 41 queries.

**Technical.** A pattern where one query is made for each row of a result.

**Example.** _The N+1 problem was slowing down the order list._
