# QC (Quality Control) · Control de calidad

**En simple.** Es revisar lo que ya está construido para detectar fallas antes de entregarlo. A diferencia de QA, que previene, QC comprueba el resultado.

**Técnica.** Quality Control: inspección del resultado para verificar conformidad.

**Ejemplo de uso.** _El control de calidad rechazó la entrega por dos fallas._

---

**In simple.** Checking what has already been built to spot faults before delivering it. Unlike QA, which prevents, QC checks the result.

**Technical.** Quality Control: inspection of the result to verify conformity.

**Example.** _Quality control rejected the delivery over two failures._
