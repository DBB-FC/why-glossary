# Hosting · Alojamiento web

**En simple.** Es el servicio que guarda tu sitio web en un servidor conectado a internet para que cualquiera pueda visitarlo.

**Técnica.** Servicio que aloja una aplicación o sitio para hacerlo accesible.

**Ejemplo de uso.** _El hosting del sitio cuesta veinte dólares al mes._

---

**In simple.** The service that keeps your website on a server connected to the internet so anyone can visit it.

**Technical.** A service that hosts an application or site so it can be accessed.

**Example.** _The site's hosting costs twenty dollars a month._
