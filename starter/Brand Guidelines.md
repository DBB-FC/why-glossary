# Brand Guidelines · Manual de marca

**En simple.** Es el documento que fija cómo se usa una marca: logos, colores, tipografías y tono, para que se vea igual en todos los materiales.

**Técnica.** Documento que establece reglas de aplicación de la identidad.

**Ejemplo de uso.** _El manual de marca define los colores permitidos._

---

**In simple.** The document that sets out how a brand is used: logos, colors, typefaces and tone, so that it looks the same on all materials.

**Technical.** A document setting the rules for applying the identity.

**Example.** _The brand guidelines set the permitted colours._
