# Rubric · Rúbrica

**En simple.** Es la lista de criterios explícitos con que se puntúa una respuesta. Sin rúbrica, cada evaluación mide algo distinto.

**Técnica.** Criterios explícitos con que se puntúa una salida.

**Ejemplo de uso.** _La rúbrica puntúa exactitud, tono y fuentes._

---

**In simple.** The list of explicit criteria used to score an answer. Without a rubric, each evaluation measures something different.

**Technical.** Explicit criteria used to score an output.

**Example.** _The rubric scores accuracy, tone and sources._
