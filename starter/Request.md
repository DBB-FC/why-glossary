# Request · Solicitud

**En simple.** Es un pedido que un cliente envía a un sistema, como «dame los datos de este usuario». El sistema responde con una respuesta.

**Técnica.** Solicitud enviada por un cliente a un servicio.

**Ejemplo de uso.** _La request llegó sin el token._

---

**In simple.** A request a client sends to a system, such as «give me this user's data». The system replies with a response.

**Technical.** A call sent by a client to a service.

**Example.** _The request arrived without the token._
