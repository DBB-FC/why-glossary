# Node.js · Node.js

**En simple.** Es un entorno que permite ejecutar JavaScript fuera del navegador, por ejemplo en un servidor. Así se puede usar el mismo lenguaje en el frontend y en el backend.

**Técnica.** Entorno de ejecución de JavaScript fuera del navegador.

**Ejemplo de uso.** _El servicio de pagos corre en Node.js._

---

**In simple.** An environment that lets you run JavaScript outside the browser, for example on a server. This way the same language can be used on the frontend and the backend.

**Technical.** A JavaScript runtime environment outside the browser.

**Example.** _The payments service runs on Node.js._
