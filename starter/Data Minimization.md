# Data Minimization · Minimización de datos

**En simple.** Es el principio de recoger y guardar solo los datos personales que de verdad se necesitan para un fin concreto. Un dato que no se tiene no se puede filtrar.

**Técnica.** Principio de recopilar solo los datos necesarios para una finalidad.

**Ejemplo de uso.** _Por minimización de datos, no pedimos la fecha de nacimiento._

---

**In simple.** The principle of collecting and keeping only the personal data that is truly needed for a specific purpose. Data you do not hold cannot be leaked.

**Technical.** The principle of collecting only the data needed for a purpose.

**Example.** _Following data minimization, we don't ask for the date of birth._
