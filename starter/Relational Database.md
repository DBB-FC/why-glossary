# Relational Database · Base de datos relacional

**En simple.** Es una base de datos que organiza la información en tablas conectadas entre sí por claves, como clientes, pedidos y productos.

**Técnica.** Base de datos organizada en tablas relacionadas mediante claves.

**Ejemplo de uso.** _Usamos una base relacional para la facturación._

---

**In simple.** A database that organizes information into tables connected to each other by keys, such as customers, orders and products.

**Technical.** A database organised in tables related through keys.

**Example.** _We use a relational database for invoicing._
