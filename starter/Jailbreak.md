# Jailbreak · Jailbreak (evasión de restricciones)

**En simple.** Es una técnica con la que alguien le habla directamente al modelo para que se salte sus restricciones. No es lo mismo que la inyección de instrucciones, que se esconde en datos que el modelo lee.

**Técnica.** Técnica para saltarse las restricciones del modelo.

**Ejemplo de uso.** _Probaron un jailbreak contra el asistente._

---

**In simple.** A technique where someone talks directly to the model to get it to skip its restrictions. It is not the same as prompt injection, which hides in data the model reads.

**Technical.** A technique for getting around the model's restrictions.

**Example.** _They tried a jailbreak against the assistant._
