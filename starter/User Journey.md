# User Journey · Recorrido del usuario

**En simple.** Es el recorrido completo de una persona con un producto o servicio, de principio a fin, con lo que hace, piensa y siente en cada etapa.

**Técnica.** Representación de etapas e interacciones de un usuario para lograr un objetivo.

**Ejemplo de uso.** _El user journey va desde descubrir la marca hasta renovar._

---

**In simple.** A person's whole path with a product or service, from start to finish, including what they do, think and feel at each stage.

**Technical.** A representation of the stages and interactions a user goes through to reach a goal.

**Example.** _The user journey runs from discovering the brand to renewing._
