# Prototype · Prototipo

**En simple.** Es una versión simulada del producto en la que se puede navegar y probar, hecha antes de construirlo para comprobar si funciona para las personas.

**Técnica.** Modelo interactivo utilizado para validar comportamiento y experiencia antes de desarrollar.

**Ejemplo de uso.** _Probamos el prototipo con cinco usuarios._

---

**In simple.** A simulated version of the product that can be navigated and tried out, made before building it to check whether it works for people.

**Technical.** An interactive model used to validate behaviour and experience before development.

**Example.** _We tested the prototype with five users._
