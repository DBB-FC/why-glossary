# Authentication (AuthN) · Autenticación

**En simple.** Es comprobar que quien intenta entrar es realmente quien dice ser, por ejemplo con una contraseña, un código o una huella. Responde «¿quién eres?».

**Técnica.** Proceso de verificar la identidad de un usuario o sistema.

**Ejemplo de uso.** _La autenticación falla si la clave es incorrecta._

---

**In simple.** Checking that whoever tries to get in really is who they say they are, for example with a password, a code or a fingerprint. It answers «who are you?».

**Technical.** The process of verifying the identity of a user or system.

**Example.** _Authentication fails if the password is wrong._
