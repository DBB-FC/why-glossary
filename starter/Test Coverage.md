# Test Coverage · Cobertura de pruebas

**En simple.** Es un porcentaje que indica cuánto del código es ejecutado por las pruebas. Un 100 % no garantiza que no haya errores: solo dice qué se probó, no qué tan bien.

**Técnica.** Medida de cuánto código o comportamiento está cubierto por pruebas.

**Ejemplo de uso.** _Tenemos 80 % de cobertura en el módulo de pagos._

---

**In simple.** A percentage showing how much of the code is run by the tests. 100% does not guarantee there are no errors: it only says what was tested, not how well.

**Technical.** A measure of how much code or behavior is covered by tests.

**Example.** _We have 80% coverage in the payments module._
