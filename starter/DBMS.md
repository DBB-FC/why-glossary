# DBMS · Sistema de gestión de bases de datos

**En simple.** Es el programa que administra una base de datos: guarda los datos, responde las consultas y controla quién accede. PostgreSQL y MySQL son ejemplos.

**Técnica.** Database Management System: software que administra una base de datos.

**Ejemplo de uso.** _Elegimos un DBMS open source._

---

**In simple.** The program that manages a database: it stores the data, answers queries and controls who has access. PostgreSQL and MySQL are examples.
