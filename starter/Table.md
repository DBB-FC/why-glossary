# Table · Tabla

**En simple.** Es una colección de datos organizada en filas y columnas, como la de clientes, ventas o usuarios.

**Técnica.** Estructura de filas y columnas dentro de una base relacional.

**Ejemplo de uso.** _La tabla clientes tiene doce columnas._

---

**In simple.** A collection of data organized in rows and columns, such as customers, sales or users.

**Technical.** A structure of rows and columns inside a relational database.

**Example.** _The customers table has twelve columns._
