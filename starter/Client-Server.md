# Client-Server · Cliente-servidor

**En simple.** Es un modelo en que un cliente, como el navegador, pide información o servicios a un servidor, que responde. Así funciona casi toda la web.

**Técnica.** Modelo donde clientes solicitan recursos o servicios a servidores.

**Ejemplo de uso.** _En cliente-servidor, el navegador pide y el servidor responde._

---

**In simple.** A model where a client, such as the browser, asks a server for information or services and the server replies. This is how almost the whole web works.

**Technical.** A model where clients request resources or services from servers.

**Example.** _In client-server, the browser asks and the server answers._
