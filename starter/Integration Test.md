# Integration Test · Prueba de integración

**En simple.** Es una prueba que comprueba que varias piezas de un sistema funcionan bien juntas, por ejemplo que una aplicación guarda correctamente sus datos en la base de datos.

**Técnica.** Prueba de interacción entre componentes o servicios.

**Ejemplo de uso.** _La prueba de integración confirmó que la API habla con la base._

---

**In simple.** A test that checks that several parts of a system work well together, for example that an app correctly saves its data in the database.

**Technical.** A test of the interaction between components or services.

**Example.** _The integration test confirmed the API talks to the database._
