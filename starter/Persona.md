# Persona · Persona (arquetipo de usuario)

**En simple.** Un usuario típico descrito en detalle para diseñar pensando en él: por ejemplo, un gerente que quiere digitalizar sin un equipo de TI.

**Técnica.** Representación estructurada de un tipo de usuario o comprador.

**Ejemplo de uso.** _Armamos tres personas para el producto._

---

**In simple.** A typical user described in detail so you design with them in mind: say, a manager who wants to digitise without an IT team.

**Technical.** A structured representation of a type of user or buyer.

**Example.** _We built three personas for the product._
