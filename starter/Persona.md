# Persona · Persona (arquetipo de usuario)

**En simple.** Es un usuario típico, inventado a partir de datos reales y descrito en detalle, para diseñar pensando en él. Por ejemplo: un gerente que quiere digitalizar sin un equipo de TI.

**Técnica.** Representación estructurada de un tipo de usuario o comprador.

**Ejemplo de uso.** _Armamos tres personas para el producto._

---

**In simple.** A typical user, invented from real data and described in detail, so you can design with them in mind. For example: a manager who wants to digitize without an IT team.

**Technical.** A structured representation of a type of user or buyer.

**Example.** _We built three personas for the product._
