# Payment Webhook · Webhook de pago

**En simple.** Es un aviso automático que el proveedor de pagos envía a tu sistema cuando un pago cambia de estado, por ejemplo de pendiente a pagado.

**Técnica.** Notificación que el proveedor envía al comercio cuando cambia el estado de una transacción.

**Ejemplo de uso.** _El webhook de pago confirmó la aprobación._

---

**In simple.** An automatic notice the payment provider sends to your system when a payment changes state, for example from pending to paid.

**Technical.** A notification the provider sends to the merchant when a transaction's status changes.

**Example.** _The payment webhook confirmed the approval._
