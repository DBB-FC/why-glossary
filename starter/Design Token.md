# Design Token · Token de diseño

**En simple.** Permite consistencia técnica del sistema visual.

**Técnica.** Variable reutilizable que representa decisiones de diseño como color, espacio o tipografía.

**Ejemplo de uso.** _El token de color primario cambia en toda la app a la vez._

---

**In simple.** Keeps the visual system technically consistent.

**Technical.** A reusable variable that represents design decisions such as colour, spacing or typography.

**Example.** _The primary colour token changes across the whole app at once._
