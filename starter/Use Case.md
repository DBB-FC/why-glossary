# Use Case · Caso de uso

**En simple.** Es la descripción de un escenario concreto en que alguien usa un sistema para lograr algo, como «el vendedor crea una cotización».

**Técnica.** Descripción de cómo un actor utiliza un sistema para alcanzar un objetivo.

**Ejemplo de uso.** _El caso de uso principal es que el vendedor genere una cotización._

---

**In simple.** The description of a specific scenario in which someone uses a system to achieve something, such as «the salesperson creates a quote».

**Technical.** A description of how an actor uses a system to reach a goal.

**Example.** _The main use case is a salesperson generating a quote._
