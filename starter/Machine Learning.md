# Machine Learning · Aprendizaje automático

**En simple.** Es una forma de crear sistemas que aprenden patrones a partir de ejemplos y datos, en vez de que alguien les escriba todas las reglas a mano.

**Técnica.** Métodos que aprenden patrones a partir de datos para realizar predicciones o decisiones.

**Ejemplo de uso.** _El modelo de aprendizaje automático predice qué clientes cancelan._

---

**In simple.** A way of building systems that learn patterns from examples and data, instead of someone writing all the rules by hand.

**Technical.** Methods that learn patterns from data to make predictions or decisions.

**Example.** _The machine learning model predicts which customers will cancel._
