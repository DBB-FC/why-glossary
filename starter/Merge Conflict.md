# Merge Conflict · Conflicto de fusión

**En simple.** Es el problema que aparece cuando dos personas cambian la misma parte del código y Git no puede decidir cuál versión conservar, así que alguien debe elegir.

**Técnica.** Incompatibilidad que Git no puede resolver automáticamente.

**Ejemplo de uso.** _Hubo un conflicto de fusión en el archivo de configuración._

---

**In simple.** The problem that appears when two people change the same part of the code and Git cannot decide which version to keep, so someone has to choose.

**Technical.** An incompatibility Git cannot resolve automatically.

**Example.** _There was a merge conflict in the config file._
