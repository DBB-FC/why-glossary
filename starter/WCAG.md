# WCAG · Pautas de accesibilidad para el contenido web

**En simple.** Son las normas internacionales de accesibilidad para sitios web. Indican, por ejemplo, el contraste mínimo de los colores y cómo hacer que todo funcione solo con teclado.

**Técnica.** Web Content Accessibility Guidelines: estándar internacional de recomendaciones de accesibilidad web.

**Ejemplo de uso.** _Apuntamos al nivel AA de WCAG._

---

**In simple.** The international accessibility standards for websites. They state, for example, the minimum color contrast and how to make everything work with the keyboard alone.

**Technical.** Web Content Accessibility Guidelines: the international standard of web accessibility recommendations.

**Example.** _We are aiming for WCAG level AA._
