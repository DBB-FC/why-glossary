# DNS · Sistema de nombres de dominio

**En simple.** Es el sistema que traduce nombres de sitios, como ejemplo.cl, en las direcciones numéricas que usan los computadores. Funciona como una agenda telefónica de internet.

**Técnica.** Sistema que traduce dominios a direcciones y servicios de red.

**Ejemplo de uso.** _El cambio de DNS tardó una hora en propagarse._

---

**In simple.** The system that translates site names, like example.com, into the numeric addresses computers use. It works like the internet's phone book.

**Technical.** The system that translates domains into network addresses and services.

**Example.** _The DNS change took an hour to propagate._
