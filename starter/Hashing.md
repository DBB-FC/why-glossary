# Hashing · Hash (resumen criptográfico)

**En simple.** Es una función que convierte cualquier dato en un código fijo que no se puede revertir. Las contraseñas se guardan así para no almacenarlas en texto plano.

**Técnica.** Función unidireccional utilizada para representar datos de forma no reversible.

**Ejemplo de uso.** _Guardamos las contraseñas como hash, nunca en texto plano._

---

**In simple.** A function that turns any piece of data into a fixed code that cannot be reversed. Passwords are stored this way so they are not kept in plain text.

**Technical.** A one-way function used to represent data in a non-reversible way.

**Example.** _We store passwords as hashes, never in plain text._
