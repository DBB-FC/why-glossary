# Data Validation · Validación de datos

**En simple.** Un email debe parecer email; un precio no debería ser texto libre.

**Técnica.** Reglas para verificar que los datos cumplen formatos y restricciones.

**Ejemplo de uso.** _La validación rechaza correos sin arroba._

**In simple.** An email must look like an email; a price shouldn't be free text.

**Technical.** Rules to verify that data meet formats and constraints.
