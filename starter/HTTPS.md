# HTTPS · HTTP seguro

**En simple.** Es HTTP con cifrado: lo que viaja entre tu navegador y el sitio no se puede leer por el camino. Se reconoce por el candado en la barra de direcciones.

**Técnica.** HTTP protegido mediante TLS.

**Ejemplo de uso.** _Activamos HTTPS en todo el sitio._

---

**In simple.** HTTP with encryption: what travels between your browser and the site cannot be read along the way. You recognize it by the padlock in the address bar.

**Technical.** HTTP protected with TLS.

**Example.** _We enabled HTTPS across the whole site._
